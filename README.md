# HR Pulse
![tests](https://github.com/VaSeBa/hr-pulse/actions/workflows/tests.yml/badge.svg)

Десктопное приложение кадровой аналитики: загружает выгрузку сотрудников из 1С:ЗУП
и строит отчёты для руководства — численность, текучесть, удержание, стоимость текучести.

> Статус: в разработке. Учебный проект.

## Принципы
- Работает полностью локально, ничего не отправляет в интернет.
- Персональные данные (ФИО, СНИЛС) маскируются при экспорте.
- Для разработки и демонстрации используются только сгенерированные данные.

## Стек
Python 3.12 · pandas · SQLite · PySide6 · Plotly · pytest · ruff · uv

## Запуск для разработки
```bash
uv sync              # установить зависимости
uv run hr-pulse      # запустить приложение
uv run pytest        # запустить тесты
```
